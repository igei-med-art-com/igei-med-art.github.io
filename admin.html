1. アクセストークン

トークンの作り方（最初の1回だけ）
  1. GitHubにログインし Fine-grained token の作成ページ を開く
  2. Token name: 任意（例 igei-admin）／ Expiration: 1年など
  3. Repository access →「Only select repositories」→ newnetjp/igei を選択
  4. Permissions → Repository permissions → Contents: Read and write
  5. 「Generate token」→ 表示されたトークン（github_pat_…）を下に貼り付けて保存

3. 各項目

「概要」は添付文書に数行だけ出ます（空欄なら COMING SOON）。「記事」は MORE を押した先の詳細ページに上から順に並びます。 全項目の記事のうち保存が新しい3件が添付文書の【近況・RECENT WORKS】に、記事の1枚目の画像をサムネイルにして出ます。

トークンを設定すると編集フォームが表示されます。
